# Reverse a String

**Difficulty:** Easy

**LeetCode:** https://leetcode.com/problems/reverse-string/

## Approach

Use two pointers, one starting from the beginning of the string and the other from the end. Swap the characters at both positions and move the pointers toward the center until the string is reversed.

## Time Complexity

O(n)

## Space Complexity

O(1)

## Notes

The string is reversed in-place without using another array. The solution was tested with a typical string and a single-character edge case before submitting to LeetCode.
